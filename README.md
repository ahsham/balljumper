## Features

- **Bot Rival Mode** — the bot dynamically responds to your performance:  
  • If you fall behind, it gives you a nudge.  
  • If you slip up, it surges ahead.  
- **Flow mechanic** — perfect clean runs build up “Flow”, accelerating up to **+35%**.  
- **Boost pickups** (⚡) — +35% speed boost for 3 seconds. These stack with Flow, NOS, Lead Bonus.  
- **NOS (Nitro)** — hold → (or **D**) for a speed burst; drains, then recharges.  
- **Shields, Hearts & Coins**  
  • Shield: smash one obstacle safely; also gives bonus.  
  • Hearts: extra lives, up to a max of 5.  
  • Coins: for score (+100 each).  
- **Lead Bonus** — staying ahead adds extra speed/score bonuses.  
- **Persistent Progress** — level, best score, and lives are saved locally on your device.
